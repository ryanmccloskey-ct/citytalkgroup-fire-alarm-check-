# CityTalk Group fire alarm service sheet

A mobile-friendly form for engineers to record a fire alarm service or maintenance check (BS 5839-1:2017, Clause 45).

## Using it

Open the page in any browser on a phone, tablet or computer. Drafts save in that browser. When the sheet is complete, download the PDF or copy the summary and email it to support@citytalkgroup.co.uk.

## Features

- Layout that works on phones and tablets, with large tap targets
- On-screen signatures for the engineer and the responsible user
- Progress through the 14 checks, plus a list of anything missing
- Device test record with as many devices as needed
- A4 PDF export (uses jsPDF from cdnjs, so it needs a connection)
- Screen reader labels, keyboard focus styles, dark mode and reduced-motion support

## Publish with GitHub Pages

1. Go to **Settings > Pages**.
2. Choose **Deploy from a branch**, then pick `main` and `/ (root)`, and save.
3. After a minute or two the form is live at `https://ryanmccloskey-ct.github.io/citytalkgroup-fire-alarm-check-/`.
